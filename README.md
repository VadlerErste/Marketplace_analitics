# Мониторинг ключевых метрик для повышения эффективности продаж, удержания пользователей.
*Разработка аналитического дашборда на основе данных Заказчика о продажах и поведении пользователей маркетплейсов*

Название отчёта:    **Финальный аналитический дашборд по продажам маркетплейса**

Бизнес-цель отчёта: **Мониторинг ключевых метрик для повышения эффективности продаж, удержания пользоватаелей**	

Целевая аудитория:  **Отдел маркетинга, аналитики, продуктовые менеджеры**

*Для аналитики данных по требованию Заказчика на базе Apache Superset был разработан аналитический отчет с тремя вкладками:*
## Аналитика продаж:
- Выявление динамики изменения основных маркетинговых метрик,количества покупателей и продавцов на платформе,увидеть наиболее эффективные сегменты рынка и точки роста
